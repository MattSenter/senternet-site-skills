## What this project is

senternet-site-skills (github: MattSenter/senternet-site-skills) — a repository of Claude Code skills on default branch `main`.

It is a pack of prompt-engineered skills for spinning up production-ready marketing sites. Each directory under `.claude/skills/` contains a `SKILL.md` and becomes a `/senternet-*` slash command in Claude Code (or `$senternet-*` in Codex). There is no application code here — the deliverable is the prompt content itself, aimed at operators building and deploying Senternet-style sites.

## Repository layout

- `.claude/skills/` — one directory per skill; each holds a `SKILL.md` (the skill body) plus any supporting reference files. This is the entire product surface.
- `.claude/settings.local.json` — local Claude Code settings (permissions/config); not part of the skill pack.
- `README.md` — install paths (`npx skills add .`, copying or symlinking into `~/.claude/skills/` and `~/.agents/skills/`), prerequisites, and example sites.
- `AGENTS.md` / `CLAUDE.md` — agent-facing instructions for working in this repo; read both before editing skills.
- `senternet-site-skills.iml` — IntelliJ module file; incidental.

## Conventions

- Skill naming: skill directories are `senternet-*`, matching the slash command they expose.
- Each skill lives in its own directory with `SKILL.md` as the entry point.
- Skills reference each other by name; keep names stable, since renaming breaks both cross-references and any installed copies in `~/.claude/skills/`.

## Invariants

- Every skill directory must contain a `SKILL.md`; the directory name is the command name.
- Project-scoped `gcloud` and `firebase` commands written into skills must always pass `--project` with the exact project. The only exceptions are account-scoped auth checks such as `gcloud auth list` and `firebase projects:list`.
- No application code belongs in this repo — it is prompt content only.

## Gotchas

- Users may have copied or symlinked skills into `~/.claude/skills/` and `~/.agents/skills/`. Copies go stale after edits here; symlinked installs pick up changes immediately.
- Skills assume external tooling on the operator's machine (Node.js and `npm`, the `skills` CLI, authenticated `gcloud` and Firebase CLI, a Google account owning the Firebase/GA4 resources). Instructions that assume these cannot be exercised in this repo.
- Nothing here is executed or type-checked, so mistakes surface only when an agent runs the skill against a real site. Proofread commands and paths carefully.
